# TestCheck

> property-based testing tool inspired by QuickCheck. The core idea of test.check is that instead of enumerating expected input and output for unit tests, you write properties about your function that should hold true for all inputs

GitHub: [clojure/clr.test.check](https://github.com/clojure/clr.test.check)
